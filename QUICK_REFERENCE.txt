🔧 TROUBLESHOOTING

Problem: "VPS connection failed"
→ Check VPS_HOST is correct (not localhost for remote)
→ Check port 5000 is open on VPS firewall
→ Test: curl http://VPS-IP:5000/api/health

Problem: "Invalid bot token"
→ Token must be from Discord Developer Portal
→ Format: Prefix(M/N) . 6-7chars . 27chars
→ Check token wasn't corrupted when copying

Problem: Bot doesn't appear online
→ Check VPS logs for errors
→ Verify auth tokens match on both sides
→ Restart VPS worker: node vps-worker-template.js
